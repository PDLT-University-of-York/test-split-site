# "Anonymous Assignment" End of Life

!!! Summary

    The "Anonymous Assignment" tool has been used on the Learn VLE (vle.york.ac.uk) for the past decause to collect student summative, anonymous assignments, and generate feedback form templates and more. This tool is being "End of Lifed" in the summer of 2023, and [replaced with TurnItIn Feedback Studio](https://vle-support.york.ac.uk/eassessment/).


## Background
The anonymous assignment building block will be taken out of service on 30th September 2023.

We expect all "in VLE" file based assessments for 23/24 to be setup using the new Turnitin Feedback Studio submission points from within a BlackBoard Learn Ultra site. The section below provides guidance which we hope should be appropriate for both undergraduate and postgraduate taught programmes for 22/23.

If you believe the proposed timings will not work for any of your assessment activities, please contact vle-support@york.ac.uk and we will discuss what additional support may be required. 

## Important Dates & Considerations

Up to and including 15th September 2023:

- Recommended approach and rationale: 
    - This should be the latest submission point deadline which uses the anonymous assignment building block.
- Late or extended submissions: 
    - The anonymous assignment building block submission point can continue to receive submissions for late or extended deadlines for a further two weeks until 29th September. 
    - Late or extended submissions after 29th September will need to be received either by email, or using a Turnitin Feedback Studio submission point set up in an Ultra site – the anonymous assignment building block will not be available after this point. 
    - Note all papers submitted to these submission points must be downloaded on (or before) 29th September.

After 15th September 2023:

- Recommended approach and rationale: 
    - Submissions must be received in a new Ultra site using a Turnitin Feedback Studio submission point 
- Late or extended submissions: 
    - The Turnitin Feedback Studio submission point can continue to receive late or extended submissions indefinitely.
