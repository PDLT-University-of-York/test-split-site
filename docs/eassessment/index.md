# eAssessment

!!! Summary
    Various tools and platforms are available for eAssessment (electronic assessment) activity here at York. Between academic years 2022/23 and 2023/24 big changes have occurred around what tools are available, and how they should be used.

    Please use the menu options to the left for guidance on which eAssessment tool to use when, and important information to know when using eAssessment tools.

    More information will be added to this section soon, covering in more detail the tools available for 2023/24 and beyond.
