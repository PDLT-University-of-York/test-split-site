# Mentimeter staff case studies

!!! Summary
    Examples from staff at the University of York of how they are using Mentimeter to support active and inclusive learning.

!!! Warning
    Mentimeter makes an integration with PowerPoint available via office 365, but this is not currently supported at the University.
    
    There are no official Google Slides ‘add-ons’ for Mentimeter so please do not install any add-ons that promise to integrate Mentimeter with Google Slides. These add-ons are unlikely to be effective and may constitute a security risk.

This guide begins with a summary of each option designed to help you choose the option that will work best for your needs. This includes advantages and disadvantages, and an estimated difficulty level for each.  There are then step-by-step instructions on each of the three options covering preparation, presenting and sharing.
