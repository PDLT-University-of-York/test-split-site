# Creating a  presentation

!!! Summary
     Create your first Mentimeter presentation and learn about question and content slides.

For an introductory video and an overview of the 'My presentations' dashboard, please see the following links:

[Video tutorial: Create your first Mentimeter presentation](https://www.youtube.com/watch?v=VpbXY98R39c&list=PLsFGssspaTWesA5nFt5OxxuFuBoWySJ-q&index=2) (you tube 1 min 51 secs) | [The Mentimeter dashboard](https://help.mentimeter.com/en/articles/410450-your-dashboard) | [Using folders](https://help.mentimeter.com/en/articles/1183596-folders-in-mentimeter)

You can use a variety of question types within your Mentimeter presentations and guidance is available on a number of these within these pages, with links to the relevant 'how to' pages.  You can also use Mentimeter to build content slides which make it possible to present an entire presentation using Mentimeter if you wish.  You can also use engagement and response tools such as Q&A and emoji reactions as well as mentimote (see the 'presenting' guidance below for more information) throughout your presentation.
