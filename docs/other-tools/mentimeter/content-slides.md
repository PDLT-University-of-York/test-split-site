# Content slides

!!! Summary
     You can use Mentimeter content slides to create accessible presentations and run entire presentations within Mentimeter

You can create [Mentimeter content slides](https://help.mentimeter.com/en/articles/410480-content-slides-in-mentimeter) which make it possible to present an entire presentation using Mentimeter if you wish.

Mentimeter content slides can include headings, bullet points, images and videos, and there is instant access to a library of copyright free images and gifs. Although content slides do not include the options available in PowerPoint or Google Slides for complex layouts and elements such as transitions and animations, a number of staff have provided feedback that they value the use of Mentimeter content slides for simplifying the layout of presentations and ensuring accessibility.
