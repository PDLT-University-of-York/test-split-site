# Other Tools

!!! Summary
    We have various other, less-widely-used learning technology tools available at York. Use the menu at the left to learn more about them, such as Padlet for virtual noticeboards and Xerte for creating interactive content, both of which can be embedded in the Learn and Canvas VLEs! 
    
Find the guide you need by:

- exploring the categories and guides in the left menu (or hamburger icon in the top left of a small screen).
- using the search box above.
