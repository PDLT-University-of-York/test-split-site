# System Data & Analytics

!!! Summary

    The Learn VLE, Canvas VLE, Replay lecture capture (aka Panopto), Collaborate Ultra and Zoom platforms all have basic data reporting functionality built in. 

## Important - Please Note

The data from our systems ***can*** be used as a general indicator for activity and involvement around your online materials, but should **not** be used as a ‘watertight’ attendance/engagement tracking tool, and **not** be used to make decisions about the performance of an individual.

## Guidance

See our related guide for  information on what data is available and how to access it: [Interaction Data - Learn & Canvas VLEs, Replay, Collaborate and Zoom](https://docs.google.com/document/d/1ZTEYp3t6HP9Fdz5vuY2wGK7tcahJMXsQhceeV3OcPIY/edit?usp=sharing).
