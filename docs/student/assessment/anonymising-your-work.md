Anonymising Your Work
For anonymous summative assignments, you will need to anonymise your files before submitting. It is your responsibility to ensure your name, exam number, and any other personally identifiable information does not appear on your file. This includes: 

The file name - ensure you rename it to something that doesn't identify you
The file contents - do not include your name or exam number anywhere in the file
The file metadata - such as 'author name' or 'last modified by'. 
Removing metadata from your file
On a windows computer for word, excel, or powerpoint:
Open the document you want to anonymise 

On the file tab, select info 
Select check for issues, and then 'inspect document' 
Select the areas you want to check for author information, then click 'inspect'
Select 'remove all'. Save the file.
For more information, you can follow these instructions.

On a mac computer for word or excel:
Go to Tools > Protect Document, and check the box "Remove personal information from this file on save". Then save the file. 

For powerpoint: 
File > Properties, and manually delete any identifying information in the fields on the summary tab, and the 'properties' box of the custom tab. Save the file. 

When creating a pdf: 
If you are converting something into a pdf, you can anonymise it as you convert. Click on 'more options' in the Save As menu, then: 

Delete all content out of the Author’s field beneath the Save as Type dropdown. The field is editable if you click on it.
Click on the Options button.
Untick box by Document Properties.
Click OK. Click save. 
Anonymising an existing pdf: 
Open the file within Corel PDF Fusion (available on all IT Classroom PCs).

Click on the Document menu option, then pick Document Settings from the menu list that appears.
Ensure you’re on the Summary tab (this is the one you should be on by default).
Delete all content out of the Author field.
Click OK.
