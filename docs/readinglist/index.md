# Reading List

!!! Summary
    Module readings (eg. book chapters, journal papers) must be provided using the Reading List tool. This is included in site templates.

## Reading list benefits

- The Library ensure appropriate stock levels and manage copyright compliance. 
- All module readings are collated in an easily accessible location rather than needing to navigate through the site.
- Items are directly accessible through single-sign-on, giving a more seamless and accessible experience.
- Individual items can also be linked to from weekly or topic-based materials sections.


## Finding guides

Locate the guide you need by:

- selecting a guide from the left menu (or hamburger icon in the top left of a small screen).
- using the search box above.
- using the next/previous links at the bottom of the page.
