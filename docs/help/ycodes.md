# Finding a YCode

!!! Summary
    The YCode is an identifier that's unique to each VLE site, and helps us quickly find and access the site you need help with.

## In an Ultra site 
If you're already in your Ultra site, the YCode is displayed above the name of your site in the top left of the screen

![decorative](images/ycode-site.png)

## In the Course/Communities List

If you're already in your Ultra site:

1. Go into either your [Courses](https://vle.york.ac.uk/ultra/course) or [Communities](https://vle.york.ac.uk/ultra/organization) page (depending what type of site it is) 
2. Locate the site within the list, either manually or by using the search box at the top
3. The site’s YCode is displayed above the site name in its entry in the list.

![decorative](images/ycode-list.png)
