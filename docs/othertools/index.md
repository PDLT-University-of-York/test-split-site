# Other Tools

!!! Summary
    We have various other, less-widely-used learning technology tools available at York. Use the menu at the left to learn more about them, such as Padlet for virtual noticeboards and Xerte for creating interactive content, both of which can be embedded in the Learn and Canvas VLEs! 
    
Find the guide you need by:

- exploring the categories and guides in the left menu (or hamburger icon in the top left of a small screen).
- using the search box above.

!!! Warning

    When choosing tools, it is important to start with tools that are supported by teams at the University.  These are subject to contracts agreed between the University and the vendor which ensures prompt support (from UoY teams and vendors where issues are escalated), robust data security and agreed levels of service availability. 

    The following  page provides an overview of available tools and links to key guidance.  You can search the tools by type of learning activity or by theme:

    [Technology-Enhanced Learning at the University of York: Tools at a glance](https://bit.ly/yorktools)

    If, after reviewing the range of University supported services, you feel that there is a gap in the University's provision and a strong rationale for using an external IT service, then you need refer to the following document before going ahead:

    [Use of external IT services for learning and teaching](https://www.york.ac.uk/about/departments/support-and-admin/information-services/information-policy/index/it-outsourcing-and-cloud-computing-policy/use-of-external-it-services-for-learning-and-teach/)

    This details important considerations such as data protection and accessibility and details the steps that are needed in order to appropriately use external tools.
