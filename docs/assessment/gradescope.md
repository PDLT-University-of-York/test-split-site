# Gradescope

!!! Summary 

    Gradescope is an assessment system being piloted in some depts in 2023/24. 
    
## What can Gradescope do?

Gradescope allows for the online marking and feedback for in-person, paper assessments, as well as direct online submission of more unusual submission types such as code files (eg. .py python files). 

Find out more: [What is Gradescope? [YouTube]](https://youtu.be/nJp_NN1oFcw)

As of Feb 2024 Gradescope has only been released to a limited number of departments for pilot/trial. If you are interested in trialling Gradescope, [contact us](mailto:vle-support@york.ac.uk) to discuss.

We are not currently able to fully support Gradescope; please refer to Gradescope's own guides and our UoY-specific guidance below before contacting us for assistance.
