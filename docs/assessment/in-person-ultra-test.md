# Onsite exams with Ultra Test

!!! Summary

    Considerations for running invigilated onsite computer exams using the Ultra Test tool.

!!! Warning

    You **must** consult the Digital Education Team if you want to set up a summative and/or synchronous exam (in person or online) using Ultra Test. [Contact us](/help/contact-us) to arrange a feasibility consultation.

## VLEEXAM system
Onsite computer exams are run in the VLEEXAM system, a separate part of the VLE with its own student accounts and non-SSO log in procedure. This means that:

- the exam can be marked anonymously.
- Duo/2Fa (and therefore access to a personal device) is not required.
- the system can be 'locked down' so that students are only able to access the exam.

**If you are interested in running an onsite exam in Ultra, you must contact us well in advance to advise on its feasibility.**

Arranging this type of exam is both costly and time consuming for many support teams as well as the department and should only be undertaken if there are no other suitable options.

## Set up the Ultra Test
For an onsite computer exam, set up the [Ultra Test](/ultra/test) in the usual way.

## Other considerations
Note that we provide technical support only, and do not provide invigilators.
