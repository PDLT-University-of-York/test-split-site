# Marking Schema

!!! Summary

    Marking schemas can be used to display an overall numerical mark as a qualitative grade or status, eg. A/B/C or Complete/Incomplete.

    This guide covers how to set up a Marking Schema, and is aimed at **Administrators** and **Teaching staff**.

This guide is under construction. For general information, see [Blackboard Help's guide to Grading Schemas](https://help.blackboard.com/Learn/Instructor/Ultra/Grade/Customize_Grading_Interface/Grading_Schemas).
