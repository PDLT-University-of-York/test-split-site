# Workshops: Ultra Bitesize

!!! Summary

    A series of workshops introducing more specialised Learn Ultra tools and features.

## Overview

!!! Tip

    Please complete the [Ultra Essentials for Teaching](https://vle-support.york.ac.uk/ultra/workshop-ultra-essentials-teaching) or Ultra Essentials for Admin training before starting these workshops.

This workshop series introduces:

- Discussions
- Groups
- Tests
- Ultra Assignments (note: not Turnitin)

We run these workshops regularly. If you'd like to attend a session, see our [Workshop calendar](https://vle-support.york.ac.uk/ultra/workshop-calendar) for sessions details and how to book.

## Discussions
