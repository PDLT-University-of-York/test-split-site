# Enrol a user

!!! Summary
 
    Most users are enrolled automatically, but you can also manually enrol users on a Learn Ultra course or organisation if needed.

## Text Steps

Inside the relevant Learn Ultra site:

1. Under **Details & Actions** on the left, select **Class register/View everyone on your course**.</br>
![decorative](images/enrol-user-class-register-menu.png)
2. Click the **plus icon** in the top right.</br>
![decorative](images/enrol-user-plus-icon.png)
3. **Search** for the user to enrol, using their username (abc123), email, first name or last name. 
4. Click the **small plus icon** next to their name.
5. The default **role** is Student. If you'd like to give the user a different role, select it from the drop-down list. Various roles are available, **important**: do not use the "Guest" role for individual users. [Learn more about the roles available](/ultra/course-roles/).</br>
![decorative](images/enrol-user-search-role.png)
5. Click **Save**.

The user will be able to see and access the site immediately.

!!! Tip
    Students are enrolled on sites automatically through their SITS enrollments, so you are unlikely to need to enrol students manually.

## Identify course staff

If there are many staff members enrolled on your site, you can allocate 'primary instructor' status to one or more instructors so they appear at the top of the list. See our [Course staff guide](/ultra/course-staff) for details.

## Troubleshooting 

The error "**No results found. Check the spelling and try again.**" can mean a few things:

1. There's an error in the search term; check and try again.
2. The user is already enrolled on your site and able to access it. Check by searching for them in the class register, using the magnifying glass button in the top right.
3. The user may have been enrolled on the course in the past but then been removed; this blocks them from being re-enrolled. Contact us at [vle-support@york.ac.uk](mailto:vle-support@york.ac.uk) and we can re-enrol them for you.
