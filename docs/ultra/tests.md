#### Adding a test to your Ultra site

To add a test to your Ultra site:

1. In the **Course Content** area of your Ultra site, hover your mouse over the grey divider where you want your test to appear, then click the plus icon that appears.
2. Click **Create**.
3. Click **Test** under **Assessment** in the **Create Item** pane.
4. Type a name for your test in the field at the top of the screen.
5. Click the **Test settings** gear icon, then click the checkbox labelled **Hide student names**. 
6. Click **Save** in the **Test settings** pane.
5. Add questions to your test by clicking the plus icon in the space labelled **Use this space to build your test**. See below for details of the different question types available.
6. If you want students to be able to add extra content, such as text, images, and files, at the end of the test, ensure **Allow students to add content at end of assessment** toggle is set to on. Otherwise, set this to off by clicking on it.
7. Set the test as **Visible to students** using the drop down menu at the top right of the screen.

#### Question types

The following question types are available when building a test in Ultra:

| Question type | Description |
| ----------- | ----------- |
| Calculated Formula  | Question that requires the student to make a calculation and respond with a numeric answer |
| Calculated Numeric  | Question that requires a numeric answer |
| Essay  | Question that requires a typed answer, graded manually |
| Fill in the Blank  | A phrase, sentence or paragraph with a blank space that a student provides with the missing word(s) |
| Hotspot  | Presents the student with an image and they are required to drop a pin on the hotspot(s) created by the instructor |
| Matching  | Presents the student with a column of prompts which need to be matched to items in a column of answers |
| Multiple Choice  | Presents the student with multiple answers from which they must pick the correct answer(s); students are not told if they need to choose one or multiple answers |
| True/False  | The student must choose true or false in response to a statement |
| Text  | The student can add text using Ultra’s text editor |
| Additional Content  | The student can add text using Ultra’s text editor and also attach local files from their device (e.g. a PDF or Word Document) |
