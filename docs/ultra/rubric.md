# Rubric

!!! Summary

    A rubric is a grid of criteria aligned to different performance levels, used to promote consistency and streamline marking and feedback.

    This guide covers how to set up a Rubric, and is aimed at **Administrators** and **Teaching staff**.

This guide is under construction. For general information, see [Blackboard Help's guide to Rubrics](https://help.blackboard.com/Learn/Instructor/Ultra/Grade/Rubrics).
