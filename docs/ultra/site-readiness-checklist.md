# Site readiness checklist

!!! Summary

    Identify and correct issues in areas such as accessibility, site/material visibility and student/staff enrollments before the module starts.

!!! principle "Relevant [VLE site design principles](https://vle-support.york.ac.uk/ultra/site-design-principles)"

    - 5.1 Recommended: Ensure that students can see and access module materials and content.
    - 5.2 Recommended: Complete the Site Readiness Checklist before making the site available to students.
