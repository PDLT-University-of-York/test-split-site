# Course roles in Learn Ultra UPDATE FOR ULTRA

!!! Summary

    A user's Course Role within a Learn Ultra course site or organisation determines what they can access or do on the course, e.g. whether they can create/edit/delete content, see hidden content, see assignment submissions and more.

    If you manually enroll users on a course site or organisation, you need to select the appropriate Course Role.


## Quick Guidance

There are six main Course Roles available on Learn Ultra. They have different names in Courses (ie. module sites) and Organisations, but have the same level of access.

Here is a summary of the Roles available, from the most to the least permissive. Click each role to see more details.

| Course Role        | Organisation equivalent role | Role ideal for            |
| :------           | :------------                 | :----------------------------------- |
| [Instructor](#instructor-leader)         | Leader                       | Most academic and admin staff.  |
| [Teaching Assistant](#teaching-assistant-assistant) | Assistant                    | Staff that should have limited access to enrol others, but otherwise act as an Instructor |
| [Marker](#marker-grader)             | Grader                       | Staff/GTAs who only need to mark student submissions, or who should not have edit access to content. They can see all content but can only mark student submissions.  |
| [Course Builder](#course-builder-organisation-builder)     | Organisation Builder         | Staff/GTAs who only need to build or edit course content. They can't mark student submissions. |
| [Student](#student-participant)            | Participant                  | Students studying the module, for credit or not; any user that you do not want to give read-only access to (ie, can't edit, see hidden content or mark submissions) |
| [Guest](#guest)              | Guest                        | Do not use - Guest users cannot access Ultra sites |


## More Details

More information on each Role's access level, from the most to the least permissive.

### Instructor (Leader)

Allows full access to alter and manage a Learn Ultra course or organisation.
The role given to most academic and admin staff.

Instructors can:
1. **Create/edit/delete** content and tools
2. **Manage assignments**, including seeing student submissions
3. Access and use the course’s **Control Panel**
4. **Manage enrollments**: enroll or unenroll users or alter a user's Role.
5. **See, access and edit** the course even when it’s set as **Hidden/Private**
6. **See hidden content** within the course.


### Teaching Assistant (Assistant)

Allows largely the same access as Instructors, except:

1. They can only grant the Student role to anyone they manually enrol on the course
2. They cannot unenrol any users from the course, or alter a user's Role.


### Marker (Grader)

Allows marking of standard assignment submissions, without edit access to content.
Suitable for Staff/GTAs who only need to mark student submissions, or site reviewers (before student submissions are made).

1. Markers **can**:
    1. Access the course’s **Full Grade Centre**, see and mark student submissions
    2. **See and access the course** even when it’s set as **Hidden/Private**
    3. **See hidden content** within the course
    4. **“Read only”** certain areas of the course’s **Control Panel**
2. Markers **cannot**:
    5. **Create/edit/delete** content and tools
    6. **Create/edit/delete submission points**
    7. **Enrol other users** on the course.


### Course Builder (Organisation Builder)

Allows creation, editing and deleting of course content/materials without access to student assignment submissions.
Suitable for Staff/GTAs who need to build or edit course content, but not mark student submissions.

1. Course Builders **can**:
    1. **Create/edit/delete content** and tools
    2. **Create/edit/delete submission points**
    3. **Manage enrollments**: enroll or unenroll users or alter a user's Role.
    4. **See and access the course** even when it’s set as **Hidden/Private**
2. Course Builders **cannot**:
    4. Access the **Full Grade Centre** of the course, nor any other marking areas
    5. Access **student assignment submissions**.		


### Student (Participant)

The appropriate role for students studying the module, whether for credit or not.

1. Students **can**:
    1. **Read/watch content** on your course, **submit assignments** and **interact with tools** such as discussion boards, journals, blogs, and wikis.
    2. **See the course** in their course list when it is set as **Hidden/Private**
2. Students **cannot**:
    1. **Access the course** when it is set as **Hidden/Private**
    2. **Edit other content**
    3. See **content** that is **hidden from students**
    4. See or access the **Control Panel** area of the course.

### Guest

Guests cannot access Learn Ultra courses or organisations, however, users can be assigned this role.

!!! Tip
    User groups have the Guest Role - this is correct! This automatically pulls user data from SITS and enrolls individual users with an appropriate role.
